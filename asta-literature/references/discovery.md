# Topic searches and follow-ups

Use this workflow when the user needs a defensible selection of papers. A known paper or author usually takes a single lookup. Codex manages the criteria and follow-ups in the current conversation.

1. Translate the question into inclusion criteria: population or mathematical setting, method, outcome and dates as relevant. Identify any condition that would exclude a superficially similar paper. Clarify only ambiguities that change the selection.
2. Search a few distinct keyword formulations. Include older terminology where appropriate. Record the queries and filters for a review that needs a reproducible search trail.
3. Screen titles and abstracts. Keep stable identifiers for candidates. Merge records with the same verified identity and retain version information when a preprint and published paper differ.
4. Follow references from promising papers and citations to them. Check direct citation edges when describing relationships. Fill missing metadata in batches. For an explicit claim, run snippet search within the candidate IDs.
5. Compare candidates against the criteria. Explain inclusions, consequential exclusions and unresolved cases. Label your relevance judgement as your own. Stop when the requested scope is covered, or report which criteria still lack evidence after trying another formulation.

**Example.** For distribution-free prediction intervals under covariate shift, search the terms “weighted conformal prediction” and “covariate shift prediction intervals”. Screen for the assumed shift model and the type of coverage. Trace papers citing a seed and check the methods or theorem statement before calling a result an extension. A search for follow-up work can return papers that only mention the seed.

For “now keep only finite-sample results”, carry forward the identified candidates, re-evaluate the new criterion and search further if a gap remains. When asked to save the search, use the project's existing note format. Include queries, dates, IDs, inclusion reasons and evidence locations so another session can resume.
